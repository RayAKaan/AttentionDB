# Datasets (§7)

All corpora are synthetic and generated by `benchmarks/phase2b/src/corpora.rs`
(deterministic given seed). Dataset hashes are per-run (see registry);
hashes differ across regenerations because HNSW candidate pools are
OS-seeded (see `reproducibility.md`).

## controlled — PH2B-GATING-004 (current)

| property | value |
|---|---|
| documents | 384 |
| dimensionality | 32 |
| clusters | 4 groups × 12 clusters |
| heads | 4 (`head0..head3`) |
| head definition | head g is CLEAN (σ = 0.02) for group-g docs, NOISY (σ = 0.30) otherwise — best head is a function of the query's group |
| true vector | normalize(centroid + 0.35·u_doc) |
| queries | 300 (group i mod 4), noised centroids (0.05) |
| ground truth | exact cosine over true vectors, top-10 |
| split | 210 / 45 / 45 |
| corpus seed | 0xC0B |

## multiview — PH2B-MULTIVIEW-005 (current)

| property | value |
|---|---|
| documents | 3 000 |
| per-view dimensionality | 64 (gating input = 192-dim concatenation) |
| topics | 40 (semantic structure); 8 categories; 10 topic keywords each from a 400-word vocabulary |
| heads | 3 views: `semantic`, `lexical`, `metadata` |
| semantic view | normalize(topic_centroid + 0.6·u_sem): WHAT the doc is about |
| lexical view | normalize(hashed topic keywords + 0.6·u_lex): WHICH words it uses (FNV-mixed hashing into 64 buckets, salt 1) |
| metadata view | normalize(category one-hot + 0.6·u_meta): structured attributes |
| information split | the 0.6·u_v term is doc-UNIQUE per view: only view V can identify a specific doc's fine neighborhood; the coarse parts are shared across topics |
| queries | 1200; type cycles semantic/lexical/metadata; a type-V query carries the TARGET DOC's view-V vector (+0.03 noise); other views carry only the topic coarse vector (+0.05 noise). Query type is NOT a model input (§36) |
| ground truth | exact cosine in the QUERY'S view over all docs, top-10 |
| split | 840 / 180 / 180 |
| corpus seed | 0x1D3A |

Sample-efficiency variants (PH2B-SAMPLE-001): identical construction with
150/300/600 queries (105/210/420 train).

## Phase 2 baseline corpus (frozen)

`results/ablation.csv` comes from the Phase 2 harness
(`benchmarks/phase2`, seed 0xC0FFEE): 10 000 docs, dim 32, 100 clusters,
8 heads with the same σ ladder, GT = exact cosine over per-doc true
vectors, 100 queries, top_k 10. Its construction is documented in
`benchmarks/phase2/ablation.md`; the multiview and per-doc-true-vector
methodology fixes postdate it and are NOT retroactively applied (frozen
accepted results, spec: do not alter).
